# Salary Data Analyzer

A beginner-friendly data analysis project using Python, NumPy and pandas.

## What it does
- Generates a sample salary dataset (200 employees)
- Cleans missing values
- Analyzes salary by department, city and experience
- Calculates statistics with NumPy
- Draws charts with Matplotlib

## How to run
1. Open `salary_data_analyzer.ipynb` in Google Colab
2. Run all cells (Runtime → Run all)

## Key findings
- IT has the highest average salary
- Experience and salary are strongly correlated
